# Deployment

The full project is a Streamlit + YOLOv8 + DeepSORT application. Keep that application unchanged for a Python runtime designed for Streamlit/ML workloads.

For Vercel portfolio purposes, deploy the lightweight showcase page:

- Repository: `footfall-counter-pro`
- Root Directory: `showcase`
- Framework Preset: Other
- Build Command: none
- Output Directory: `./`

This gives the project a stable public portfolio URL without misrepresenting the heavy computer-vision runtime as a native Vercel web function.
